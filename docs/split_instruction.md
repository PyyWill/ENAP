## PMM Cluster Split Requirement

请实现一种针对 cluster label 的图结构拆分机制，规则如下：

### 目标
给定一个 PMM 有向图，当某个 cluster（如 `c1` 或 `c2`）被拆分为两个子类（如 `c1-1, c1-2`）时，同步对相关边和节点进行一致性拆分，并保持图的互斥语义不被破坏。

### 规则

1. **出边拆分**
   - 若某个节点存在标签为 `cX` 的出边，则该出边拆分为两条：
     - `cX-1`
     - `cX-2`

2. **入边触发节点拆分**
   - 若某个节点存在标签为 `cX` 的入边，则该节点拆分为两个子节点：
     - `node_1`
     - `node_2`
   - 所有原本以 `cX` 进入该节点的边，分别改为进入：
     - `node_1`（对应 `cX-1`）
     - `node_2`（对应 `cX-2`）

3. **节点拆分后的连边约束**
   - 两个子节点分别继承原节点的出边结构。
   - 但必须保持互斥性：**不能因为拆分而新增两个子节点之间的横向连边**。
   - 因此，拆分后每个子节点上的边数量应与原节点一致，图中不会出现额外的跨副本连接。

### 语义要求
- 拆分仅表示“同一 cluster 的细分”，不是新增状态可达性。
- 原本互斥的 cluster 仍保持互斥。
- 拆分前后图的局部拓扑模式保持一致，只是 label 和对应节点副本被细化。

### 示例
原图中：
- `q0 -> q1 [c2]`
- `q1 -> q1 [c2]`
- `q1 -> q3 [c1]`

若拆分 `c2 -> {c2-1, c2-2}`，且 `q1` 因入边 `c2` 被拆成 `q1_1, q1_2`，则应得到：
- `q0 -> q1_1 [c2-1]`
- `q0 -> q1_2 [c2-2]`
- `q1_1 -> q1_1 [c2-1]`
- `q1_2 -> q1_2 [c2-2]`

注意不能产生：
- `q1_1 -> q1_2`
- `q1_2 -> q1_1`

同理，若 `q3` 因入边 `c1` 被拆分，则只允许各自子节点承接对应子类入边，不允许子节点之间因为拆分而互连。
